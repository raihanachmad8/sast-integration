# Struktur yang Harus Dihindari — Bahasa Indonesia

## Kontras Biner

Ini menciptakan drama palsu. Langsung sampaikan intinya.

| Pola | Masalah |
|------|---------|
| "Bukan karena X. Tetapi karena Y." | Pembalikan yang dipaksakan |
| "X bukanlah masalahnya. Y adalah masalahnya." | Pembingkaian ulang formulaik |
| "Jawabannya bukan X. Melainkan Y." | Pivot yang bisa ditebak |
| "Terlihat seperti X. Sebenarnya Y." | Klise setup/reveal |
| "Pertanyaannya bukan X. Tapi Y." | Misdireksi retoris |
| "Bukan X. Tapi Y." | Kontras mekanis |
| "Ini bukan itu. Ini ini." | Formula sama, kata berbeda |
| "tidak hanya X, tetapi juga Y" | Tambahan basa-basi |
| "bukan sekadar X, melainkan Y" | Negasi berlebihan |
| "X namun bukan berarti Y" | Penyangkal yang tidak perlu |
| "daripada X, lebih baik Y" | Perbandingan palsu |

**Ganti:** Langsung tulis Y. "Masalahnya adalah Y." "Yang penting adalah Y." Jangan buang waktu dengan negasi.

## Daftar Negatif

Menyebut apa yang BUKAN sesuatu sebelum mengungkapkan apa yang SESUNGGUHNYA. Striptis retoris.

| Pola | Masalah |
|------|---------|
| "Bukan A… Bukan B… Ini C." | Pembangunan dramatis melalui negasi |
| "Ini bukan X. Ini bukan Y. Ini adalah Z." | Struktur sama, versi panjang |
| "Jangan bayangkan A. Jangan bayangkan B. Ini benar-benar C." | Negasi berlapis |

**Ganti:** Langsung tulis Z. Pembaca tidak butuh landasan pacu.

## Fragmentasi Dramatis

Fragmentasi kalimat untuk penekanan terbaca sebagai kedalaman palsu.

| Pola | Masalah |
|------|---------|
| "[Kata benda]. Itu saja. Itu X-nya." | Kesederhanaan yang dipaksakan |
| "X. Dan Y. Dan Z." | Staccato dramatis |
| "Ini membuka sesuatu. [Kata]. Wahyu." | Pengungkapan artificial |
| "Satu kata: [Kata]." | Clickbait |
| "Sederhana: X." | Pernyataan berlebihan |

**Ganti:** Kalimat utuh. Percayakan isi, bukan presentasi.

## Pertanyaan Retoris

Ini mengumumkan wawasan daripada menyampaikannya.

| Pola | Masalah |
|------|---------|
| "Bagaimana jika [pembingkaian ulang]?" | Sok Sokrates |
| "Apa artinya ini semua?" | Retoris kosong |
| "Lalu, apa yang bisa kita pelajari?" | Transisi malas |
| "Pernahkah Anda berpikir bahwa?" | Menggurui |
| "Sudahkah kita bertanya pada diri sendiri?" | Basa-basi |
| "Tahukah Anda?" | Clickbait |

**Ganti:** Buat intinya. Biarkan pembaca menarik kesimpulan sendiri.

## Agensi Palsu

Memberi benda mati kata kerja manusia. AI suka ini karena menghindari menyebut pelaku.

| Pola | Masalah |
|------|---------|
| "Aplikasi ini memungkinkan pengguna untuk..." | Aplikasi tidak "memungkinkan". Orang menggunakannya. |
| "Data menunjukkan bahwa..." | Data diam saja. Orang membaca dan menyimpulkan. |
| "Sistem memberikan solusi untuk..." | Sistem tidak "memberi". Orang yang membangunnya. |
| "Teknologi ini mendorong perubahan." | Teknologi tidak "mendorong". Orang yang berubah. |
| "Platform ini menghubungkan..." | Platform tidak "menghubungkan". Orang terhubung. |
| "Algoritma memutuskan bahwa..." | Algoritma tidak "memutuskan". Programmer menulis kodenya. |
| "Pasar bereaksi terhadap..." | Pasar tidak "bereaksi". Pembeli dan penjual bereaksi. |
| "Fitur ini bertujuan untuk..." | Fitur tidak punya tujuan. Orang yang merancangnya punya tujuan. |
| "Kolaborasi ini melahirkan..." | Kolaborasi tidak "melahirkan". Orang yang berkolaborasi menghasilkan. |
| "Perusahaan ini bergerak di bidang..." | Perusahaan tidak "bergerak". Orang di dalamnya bekerja. |
| "Laporan ini membahas..." | Laporan tidak "membahas". Penulis laporan membahas. |
| "Tulisan ini akan mengulas..." | Tulisan tidak "mengulas". Penulis mengulas. |

**Ganti:** Sebut manusianya. "Tim memperbaikinya dalam seminggu" lebih baik dari "Sistem menyediakan perbaikan." Jika tidak ada orang spesifik, gunakan "kamu" untuk menempatkan pembaca di kursi.

## Narator dari Kejauhan

Melayang di atas adegan daripada menempatkan pembaca di dalamnya.

| Pola | Masalah |
|------|---------|
| "Berdasarkan uraian di atas" | Suara dosen |
| "Sebagaimana diketahui" | Suara narator |
| "Dari sudut pandang X" | Jarak akademis |
| "Dalam hal ini perlu dipahami bahwa" | Pengguruan |
| "Pada umumnya, orang cenderung..." | Sosiolog kursi |
| "Masyarakat Indonesia pada umumnya..." | Generalisasi berbahaya |
| "Dari perspektif sosiologis" | Jarak buatan |
| "Perlu dipahami bahwa" | Basa-basi akademis |
| "Sebagai catatan" | Tidak perlu |

**Ganti:** Langsung ke inti. "Kamu tidak duduk suatu hari dan memutuskan untuk..." lebih baik dari "Seseorang pada umumnya cenderung untuk..."

## Kalimat Pasif

Setiap kalimat butuh subjek yang melakukan sesuatu. Pasif menyembunyikan aktor dan menguras energi.

| Pola | Perbaikan |
|------|-----------|
| "Dapat disimpulkan bahwa" | Siapa yang menyimpulkan? Saya menyimpulkan... |
| "Telah dilakukan penelitian" | Siapa yang meneliti? Tim meneliti... |
| "Dibahas lebih lanjut di bagian berikut" | Siapa yang membahas? Saya bahas di... |
| "Diperlukan langkah-langkah" | Siapa yang perlu? Kita perlu... |
| "Disepakati bahwa" | Siapa yang sepakat? Kami sepakat... |
| "Diputuskan untuk" | Siapa yang memutuskan? Manajer memutuskan... |
| "Diberikan pelatihan kepada" | Siapa yang memberi? Kami memberi pelatihan... |
| "Dibuatlah sebuah sistem" | Siapa yang membuat? Saya membuat... |

**Ganti:** Temukan aktornya. Letakkan mereka di depan kalimat. "Saya menyimpulkan" lebih baik dari "Dapat disimpulkan."

## Pembuka Kalimat yang Harus Dihindari

| Pola | Perbaikan |
|------|-----------|
| "Yang [verba]..." ("Yang perlu diperhatikan", "Yang menjadi masalah") | Restrukturisasi. Langsung ke subjek. |
| "Dalam [konteks/waktu]" ("Dalam era digital", "Dalam perkembangan") | Langsung ke konten |
| "Untuk [tujuan]" ("Untuk mengatasi masalah ini") | Langsung ke inti |
| "Melalui [cara]" ("Melalui pendekatan ini") | Langsung |
| "Bahwa [klausa]" di awal kalimat | Hapus "bahwa", tulis langsung |
| "Seiring dengan" di awal paragraf | Potong |
| "Terkait dengan" | Hapus, langsung |
| "Menurut [sumber]" di awal kalimat | Integrasikan ke dalam kalimat |
| "Tentang [topik]" | Langsung |

Kalimat pembuka dengan "Yang..." menjadi kruk. "Yang menjadi perhatian adalah..." menjadi "Perhatiannya ada pada..." atau lebih baik, sebut perhatian spesifiknya.

## Pola Ritme

| Pola | Perbaikan |
|------|-----------|
| Daftar tiga item | Gunakan dua item atau satu |
| Pertanyaan langsung dijawab | Biarkan pertanyaan bernapas atau hapus |
| Setiap paragraf berakhir dengan quotes | Variasikan akhiran |
| Em dash (—) | Hapus. Gunakan koma atau titik. |
| Fragmentasi staccato | Jangan tumpuk kalimat pendek-pendek |
| Kata penghubung berulang | "Selain itu... Selain itu... Selain itu..." variasikan |
| "Bukan tanpa alasan" | Penyangkal palsu |

## Pola Kata

| Pola | Masalah |
|------|---------|
| Kata ekstrem malas (semua, setiap, tidak pernah, selalu, seluruh, tak satu pun) | Otoritas palsu. Gunakan spesifik. |
| Kata sifat/keterangan (-nya berlebihan) | Penekanan kosong. Lihat phrases.md. |
| Akronim jargon (SDM, SOP, KPI, ROI, dll di luar konteks teknis) | Ganti dengan bahasa Indonesia yang jelas |
| Anglisisme tidak perlu (meeting, approve, pending, issue, launch) | Cari padanan Indonesianya |
