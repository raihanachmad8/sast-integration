# Frasa yang Harus Dihapus — Versi Akademik

## Filler dan Intensifier (HAPUS)

Kata-kata ini melemahkan pernyataan ilmiah. Tidak ada gunanya.

| ❌ Hindari | ✅ Ganti |
|-----------|---------|
| sangat penting | penting (atau beri data: *p < 0,01*) |
| cukup signifikan | signifikan (atau beri nilai signifikansi) |
| cukup baik | baik (atau beri tolok ukurnya) |
| agak kompleks | kompleks (atau jabarkan kompleksitasnya) |
| begitu besar | besar/sebutkan ukurannya |
| sangatlah perlu | perlu |
| sangat mungkin | probabilitasnya tinggi / beri angkanya |
| amat sangat | (hapus total — ini kontradiksi) |
| relatif lebih | lebih (relatif itu sudah implied) |
| secara umum | (sebutkan konteks spesifik atau hapus) |
| secara keseluruhan | (sudah implied dari konteks) |
| secara fundamental | (hapus, tidak menambah makna) |
| pada dasarnya | (langsung ke inti) |
| pada hakikatnya | (langsung ke inti) |
| tidak dapat dipungkiri | (argumen yang lemah — buktikan, bukan dipungkiri) |
| sudah jelas bahwa | (kalau sudah jelas, kenapa ditulis?) |
| tentu saja | (tidak ilmiah) |
| sudah pasti | (tidak ada yang pasti di sains) |
| tidak diragukan lagi | (pernyataan ini sendiri perlu diragukan) |
| terbukti bahwa | (apa buktinya?) |
| tidak bisa disangkal | (bisa — yang penting argumennya) |

## Pernyataan Kabur (HAPUS)

Kalimat yang mengumumkan wawasan tanpa menyampaikan wawasan.

| ❌ Hindari | ✅ Ganti |
|-----------|---------|
| Hal ini menunjukkan bahwa | (sebut spesifik: *Akorasi 93% menunjukkan bahwa Random Forest mampu...*) |
| Dari sini dapat disimpulkan | (langsung simpulkan) |
| Dengan demikian terlihat bahwa | (langsung) |
| Hasil ini mengindikasikan bahwa | (sebut apa yang diindikasikan secara spesifik) |
| Ini membuktikan bahwa | buktinya apa? sebut. |
| Hal ini mengonfirmasi bahwa | apa yang dikonfirmasi? |
| Berdasarkan hasil analisis | (kalau sudah jelas dari konteks, hapus. Atau langsung sebut: *Analisis menunjukkan...*) |
| Dari uraian di atas dapat dipahami | (langsung) |
| Hal ini memperkuat temuan bahwa | temuan spesifiknya apa? |
| Dengan demikian dapat ditarik kesimpulan | ("Kesimpulannya:" sudah cukup) |

## Pembuka Kosong (HAPUS)

| ❌ Hindari |
|-----------|
| Perlu diingat bahwa |
| Perlu dicatat bahwa |
| Perlu dipahami bahwa |
| Perlu diketahui bahwa |
| Sebagaimana kita ketahui |
| Seperti yang sudah diketahui |
| Tidak mengherankan bahwa |
| Menarik untuk dicermati bahwa |
| Hal yang menarik adalah |
| Patut disayangkan bahwa |
| Pada era globalisasi/modernisasi/digital ini |
| Di zaman yang serba modern ini |
| Seiring perkembangan zaman |
| Dalam dunia yang semakin kompleks |
| Tidak bisa dipungkiri bahwa |
| Terlepas dari itu |

## Klise Akademik (HAPUS atau SPESIFIKKAN)

Frasa yang menjadi template skripsi dan tidak bermakna.

| ❌ Klise | ✅ Lebih Baik |
|---------|-------------|
| Dapat dijadikan acuan bagi peneliti selanjutnya | Bisa jadi acuan untuk penelitian selanjutnya yang fokus pada [topik spesifik] |
| Perlu diteliti lebih lanjut | Penelitian selanjutnya perlu menguji [parameter/variabel spesifik] |
| Bermanfaat bagi pembaca pada umumnya | (HAPUS — terlalu generik) |
| Diharapkan dapat memberikan kontribusi | Kontribusi spesifik penelitian ini adalah... |
| Sebagai bahan pertimbangan | (untuk apa? kepada siapa?) |
| Dapat dijadikan referensi | Referensi untuk [topik spesifik] |
| Semoga bermanfaat bagi kita semua | (HAPUS — bukan kesimpulan ilmiah) |
| Dapat menjadi sumbangan pemikiran | (terlalu luhur — sebut kontribusinya langsung) |
| Memberikan wawasan yang lebih mendalam | Wawasan tentang [apa] |
| Menjadi landasan untuk pengembangan lebih lanjut | Landasan untuk [pengembangan spesifik] |
| Dari hasil penelitian ini diperoleh | (langsung sebut hasilnya) |
| Kesimpulan yang dapat diambil | (langsung: *Kesimpulan dari penelitian ini adalah...*) |
| Berdasarkan hasil dan pembahasan dapat disarankan | (langsung: *Saran untuk penelitian selanjutnya:...*) |

## Jurnal Ilmiah vs Skripsi — Bedakan

Ada frasa yang wajar di skripsi (bab penutup normatif) tapi memalukan di jurnal:

| Frasa | Skripsi | Jurnal |
|-------|---------|--------|
| Penulis menyadari bahwa... | ✅ Wajar (kata pengantar) | ❌ Jangan |
| Masih banyak kekurangan | ✅ Wajar (kata pengantar) | ❌ Jangan |
| Mohon maaf apabila ada kesalahan | ✅ Wajar (kata pengantar) | ❌ Jangan |
| Atas perhatiannya diucapkan terima kasih | ✅ Wajar (kata pengantar) | ❌ Jangan |
| Akhir kata | ✅ Wajar (kata pengantar) | ❌ Jangan |
| Penelitian ini masih jauh dari sempurna | ❌ Tidak (di mana-mana lemah) | ❌ Jangan |
| Diharapkan dapat menjadi... | ⚠️ Minimalisir | ❌ Jangan |

## Redundansi Akademik

Dua kata yang bilang hal sama. Pilih satu.

| ❌ Boros | ✅ Hemat |
|---------|---------|
| metode penelitian yang digunakan dalam penelitian ini adalah metode | metode penelitian ini adalah |
| tujuan dari penelitian ini adalah untuk | tujuan penelitian ini adalah |
| hasil dari pengujian yang telah dilakukan | hasil pengujian |
| proses analisis data yang dilakukan | analisis data |
| berdasarkan dari hasil pengujian | berdasarkan hasil pengujian |
| dapat berfungsi sebagai | berfungsi sebagai |
| saling berinteraksi satu sama lain | berinteraksi |
| guna untuk mencapai | untuk mencapai |
| pada Tabel 1 di bawah ini | pada Tabel 1 |
| seperti yang terlihat pada Gambar 1 | pada Gambar 1 |

## Terjemahan Kaku English → Indonesia Akademik

Istilah Inggris yang sebaiknya dipakai dalam bahasa Indonesia yang wajar — bukan diterjemahkan kata per kata dengan kaku.

| ❌ Terjemahan Kaku | ✅ Alternatif |
|-------------------|-------------|
| *di akhir hari (at the end of the day)* | pada akhirnya / hapus |
| *berbicara tentang (speaking of)* | langsung ke topik |
| *dalam hal (in terms of)* | dari segi / langsung |
| *tidak peduli apa pun (no matter what)* | apa pun / hapus |
| *pada saat yang sama (at the same time)* | sementara itu, namun |
| *selain daripada itu* | selain itu |
| *untuk selanjutnya* | selanjutnya |
| *oleh karena itu* (setiap paragraf) | variasikan, kadang hapus |
| *berdasarkan kepada* | berdasarkan |

## Hati-hati dengan Akronim Berlebihan di Pendahuluan

Skripsi sering menumpuk akronim di 1-2 paragraf pertama latar belakang. Ini sudah jadi klise. Misalnya: "Perkembangan Teknologi Informasi (TI) dan Artificial Intelligence (AI) di era Revolusi Industri 4.0 dan Society 5.0 telah membawa dampak yang signifikan terhadap berbagai aspek kehidupan manusia..."

➡️ **Masalah:** Pembaca sudah muak dengan deretan akronim basi ini. Langsung ke masalah spesifik yang diteliti.
