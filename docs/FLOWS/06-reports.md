# Reports Flow

## Pre-conditions
- Workspace has completed scans
- User has REPORT_VIEW permission

## Role Context
| Action | Owner | Manager | Reviewer | Member |
|--------|-------|---------|----------|--------|
| View reports | ✅ | ✅ | ✅ | ✅ |
| Generate report | ✅ | ✅ | ✅ | ❌ |
| Export/Download | ✅ | ✅ | ✅ | ❌ |
| Delete report | ✅ | ✅ | ❌ | ❌ |

## User Scenarios

### 1. Generate Report
1. User navigates to Reports page
2. Clicks "Generate report"
3. Selects report type (PDF/Excel)
4. Selects date range and filters
5. Clicks "Generate"
6. Report created, appears in list

### 2. View Report List
1. Table shows all reports with:
   - Title
   - Format (PDF/Excel)
   - Status (Pending/Ready/Failed)
   - Created date
   - Generated by

### 3. Preview Report
1. User clicks "Preview" on report row
2. Modal opens showing:
   - PDF: Embedded PDF viewer
   - Excel: Table preview with sheet tabs
3. Can navigate pages/sheets

### 4. Download Report
1. User clicks "Download" on report row
2. File downloads to local machine
3. PDF or Excel format based on report type

### 5. Delete Report
1. User clicks "Delete" on report row
2. Confirmation dialog
3. Report removed from list
4. File deleted from storage

## Report Types
| Type | Content |
|------|---------|
| Executive Summary | High-level metrics, trends |
| Detailed Findings | All findings with full details |
| Compliance | CWE/OWASP mapping |
| Custom | User-configured filters |

## Pre-condition Checks
- Report generation requires REPORT_EXPORT permission
- Preview requires REPORT_VIEW permission
- Large reports may take time to generate
